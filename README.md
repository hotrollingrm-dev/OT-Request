# OT REQUEST · HRM PROCESS

แอปขอทำงานล่วงเวลา (OT) สำหรับ HOT ROLLING — UACJ (Thailand)

**เปิดใช้:** https://hotrollingrm-dev.github.io/OT-Request/

## ติดตั้งเป็นแอปบนมือถือ

**Android (Chrome)**
เปิดลิงก์ด้านบน → รอสักครู่จะมีการ์ด "ติดตั้งเป็นแอปบนมือถือ" ขึ้นด้านล่าง → กด **ติดตั้ง**
(หรือเมนู ⋮ → **ติดตั้งแอป**)

**iPhone (Safari)**
เปิดลิงก์ด้วย **Safari** → แตะปุ่มแชร์ ⬆︎ → **เพิ่มไปยังหน้าจอโฮม** → **เพิ่ม**
(ต้องเป็น Safari เท่านั้น เปิดจากในแอป LINE จะติดตั้งไม่ได้ ให้กด "เปิดใน Safari" ก่อน)

ติดตั้งแล้วเปิดเต็มจอเหมือนแอปจริง และใช้ได้แม้ไม่มีเน็ต

## ใช้งาน

1. เลือกกะ → ทีมหลัก (คนเซ็นอนุมัติ) → พนักงาน + ประเภท OT → กด **เพิ่มลงรายการ**
2. เลือกวันที่
3. กด **ส่งใบขอ OT** ท้ายการ์ด "รายการที่ขอ" → บันทึกรูป / PDF / ส่ง LINE

## ไฟล์ใน repo

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป (ไฟล์เดียวจบ ฟอนต์/รูปฝังในไฟล์) |
| `manifest.webmanifest` | ข้อมูลแอปสำหรับติดตั้ง ชื่อ ไอคอน สี |
| `sw.js` | Service Worker ให้เปิดแบบออฟไลน์ได้ |
| `icons/` | ไอคอนแอป Android / iPhone / แท็บเบราว์เซอร์ |
| `screenshots/` | ภาพตัวอย่างในหน้าต่างติดตั้งบน Android |

## อัปเดตเวอร์ชัน

อัป `index.html` ใหม่ทับได้เลย — แอปดึงหน้าใหม่ทุกครั้งที่มีเน็ต
ถ้าเปลี่ยนไอคอนหรือไฟล์อื่น ให้เปลี่ยนเลข `CACHE` ใน `sw.js` ด้วย (เช่น `otreq-v1` → `otreq-v2`)
