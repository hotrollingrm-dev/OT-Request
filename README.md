# OT REQUEST · HRM PROCESS

แอปขอทำงานล่วงเวลา (OT) สำหรับ HOT ROLLING — UACJ (Thailand)

ไฟล์เดียวจบ (`index.html`) ไม่ต้องติดตั้ง ไม่ต้องต่อเน็ต ฟอนต์และรูปทั้งหมดฝังอยู่ในไฟล์

## ใช้งาน

1. เลือกกะ → ทีมหลัก (คนเซ็นอนุมัติ) → พนักงาน + ประเภท OT → กด **เพิ่มลงรายการ**
2. เลือกวันที่
3. กด **ส่งใบขอ OT** ท้ายการ์ด "รายการที่ขอ" → บันทึกรูป / PDF / ส่ง LINE

## ธีม

- ฉากฟาร์มโรงงานฤดูใบไม้ร่วง เปลี่ยนตามเวลาในเครื่อง (เช้า กลางวัน พระอาทิตย์ตก กลางคืน ฝน ฯลฯ)
- หน้าต้อนรับ: ชิบะใส่หมวกนิรภัยลากคอยล์อะลูมิเนียม (แตะเพื่อข้าม)
- ธีมสีเอกสาร 24 แบบ + วันพิเศษ (วันพระ สงกรานต์ ปีใหม่ ฯลฯ) มีผลกับใบขอที่ export
- ใบขอ OT ที่ export เป็นฟอร์มทางการ ฟอนต์ Kanit
